# 🎓 Git Training & Hands-On Demo Repository (`demo_repo`)

Welcome to **demo_repo**! This repository is designed as an interactive sandbox for learning and mastering essential Git workflows, branching strategies, and collaboration practices.

---

## 🎯 Purpose

This repository provides realistic scenarios to practice:
- Core Git lifecycle stages (working directory, staging area, local commit, remote push)
- Inspection tools (`status`, `diff`, `log`, `show`)
- Branching, switching, and merging workflows
- Resolving merge conflicts cleanly
- Advanced history management (`cherry-pick`, `rebase`, `stash`, `revert`, `reset`)
